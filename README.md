# Coffee Routine Protocol ☕

A lightweight protocol for a long-running morning coffee routine.

> Humans are not state machines.

## Basic Protocol

- Ask: `+1?`
- Yes: `+`, `要`, `對`, `👍`
- No: `pass`
- Either side can pause or resume anytime
- Coffee delivered: ☕
- Missed reply: no big deal
- Try again tomorrow

## Optional Features

- Coffee blind box from rotating cafés ☕
- Deferred billing ("水費") XD
